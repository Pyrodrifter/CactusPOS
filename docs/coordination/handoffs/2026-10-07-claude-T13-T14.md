- `packages/receipt`: block model, `buildReceipt` / `buildKitchenTicket` / `buildTestPage` / `wifiQr`, renderers for text, HTML and ESC/POS (CP858 encoding, QR, cut, drawer). EN + NL.

Also run end to end by hand: real server over HTTP, a stand-in TCP "printer" on 127.0.0.1, both jobs arrived intact.

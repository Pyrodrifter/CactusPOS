## What changed
- Installed launcher passes validated optional LAN settings to the same server process. The existing port
  3000/data/browser origin stays intact. An HTTP alias on port 80 makes `http://cactus.local/pos` possible.
  Port/name failure leaves checkout running and displays IP/port fallback diagnostics.
- Production mDNS probes a configurable `.local` name, advertises IPv4 and `_cactuspos._tcp.local` DNS-SD,
  detects conflicting A/AAAA/CNAME records and refreshes after LAN interface changes. No public DDNS or TLS
  certificate setup is implied. Windows firewall source adds local-subnet TCP alias and UDP 5353 rules.
- Native Java Android app under `ops/android`: saved server/role, health verification, local discovery,
  WebView origin restrictions, no file/content access or SSL bypass, keep-awake, rotation preservation,
  connection/reconnect controls and explicit native printing of existing receipt HTML. Existing network
  receipt printing stays on the Surface. No second database, payment replay or cloud dependency.
- `npm run android:build` runs native unit tests/release lint, signs the APK and verifies its signature.
  Signing material is outside the repo in `%LOCALAPPDATA%\CactusPOSBuild\android`; preserve it for updates.
- Added `ops/mobile-clients.md`, updated the EN/NL manual connection text and documented Safari Home Screen
  installation. Native iOS needs Mac/Xcode/signing; no IPA was produced. Existing web UI/screenshots are
  unchanged. Manual PDFs/new Windows setup are intentionally deferred to the next release build.

## Contracts / dependencies
- Shared `LocalNetworkSettings` / `LocalNetworkStatus`; `contracts/local-clients.md` documents the launcher
  environment/status-file boundary. Existing HTTP/WS routes, database and tax rules are unchanged.
- ADR-0003 explains the native WebView client and signing/distribution choice.
- Existing `multicast-dns` 7.2.5 is now also a **server production dependency**, required by installed discovery.
  Android has no external runtime dependency. Gradle/AGP are build tools; JUnit 4.13.2 is test-only for URL,
  unsafe-origin and navigation regressions. No key/password is in source or APK.

## What changed
- New standalone `/menu-board` display in `apps/order/MenuBoard.tsx`, with large category headings, descriptions and tax-inclusive USD prices. Only available items appear; open-price items show Market price / Dagprijs.
- Categories rotate every 15 seconds, with at most six items per page. Empty categories are omitted. Display controls support pause, previous/next, category selection, EN/NL interface labels, fullscreen and a persisted independent light/dark palette.
- Existing `/api/menu` is polled every ten seconds and on network recovery. The last successful menu remains visible after a failed refresh; initial failure shows a waiting state. No cloud dependency or order/payment operation.
- Screen tools links to the menu board in a new tab. Direct access redirects to sign-in with a fixed return destination; the board uses the existing authenticated menu endpoint. Each display must sign in once. Wake lock uses the existing lifecycle helper where supported.

## Gotchas / decisions
- This is an authenticated display, like the till, rather than a public guest menu endpoint. Menu controls allow returning to the till on the signed-in device. Use a display customers cannot operate if it is signed in as staff.
- Retains the last menu in memory during a running session, not across offline reloads. Standard PWA shell behavior remains unchanged.
- Display text uses the menu's stored item/category language. The language control translates the board interface, not menu content.

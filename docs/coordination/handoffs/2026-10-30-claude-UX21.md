# UX21: simpler menu creator, allergy marks, category colours

## What changed
- Item editor: removed the tax block, "Customer pays" line, "Type prices without ABB" switch, "Prepared at" select and hints. The price label is just "Price". Prices are still stored and charged including ABB; existing items keep their station.
- Removed the note under the item list and the station from the row.
- `MenuItem.tags` (optional): allergens and diet marks from `MENU_TAGS` in shared. Tap buttons in the editor; shown on till tiles, the till's options sheet and the menu board.
- `MenuCategory.color` (optional): eight colours from `CATEGORY_COLORS`, one tap in Admin > Menu, saved at once. Categories without a choice keep their position-based colour.
- Schema v7 adds `menu_categories.color`.

## How to test
Admin > Menu: tap a colour, open an item, tap Gluten, save. Check Order and the menu board.

## Checks
`npm run check` and `npm run e2e` (tax-admin now covers both). Screenshots of editor, colours, till and board at tablet and phone size.

## Gotchas
- Schema v7: once a till has run this build, an older build refuses that database, so a backup from it does not restore on rc.4.
- `PUT` category must always send `color`; leaving it out clears the choice. All three callers in `MenuAdmin` do.
- Marks are per item, not per order. A customer's own allergy still goes in the order note, which the kitchen shows first.
- Kitchen tickets and receipts do not show marks.
- The manual still describes the removed fields and needs new pictures.

## Follow-ups
None beyond the manual. No new dependency.

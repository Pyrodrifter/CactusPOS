## Gotchas / decisions
- New dev dependency `multicast-dns ^7.2.5` supplies standard DNS packet handling
  and multicast socket lifecycle; keeps this tool independent of cloud/DNS and
  advertises the explicitly selected interface rather than VPN addresses.
- Caddy and mkcert are external tools, not npm dependencies or committed binaries.
  Portable paths are supported. Initial installation needs internet; operating
  the configured LAN path does not.
- `lan:setup` generates a leaf but never runs `mkcert -install`; CA trust is a
  deliberate one-time device setup. Only `rootCA.pem` is shared, never CA/server
  private keys. `.local/` and test tools/certificates were not committed.
- Regenerate the leaf after hostname/IP changes. `settings.json` records generation
  settings; dev reads explicit environment settings and validates the leaf.
- Physical same-WiFi phone acceptance is still pending: no connected phone was
  available to install its root certificate and perform the Done when drill.
  Keep T06 in review until this check is recorded; software verification alone
  is not a claim that the phone trusts the certificate or receives multicast.

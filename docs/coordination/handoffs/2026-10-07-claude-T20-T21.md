# Handoff: T20 + T21 — menu admin, settings, staff
- Agent: claude   Date: 2026-10-07   Branch: agent/claude/T20

## What changed
- server `auth.ts`: PINs hashed (scrypt, plain PINs from older DBs upgraded on start), sessions stored in SQLite so a restart doesn't log devices out, login lockout after 5 wrong PINs, `/api/logout`.
- server `admin.ts`: owner-only menu/category/business/tax/staff changes, each written to an append-only `audit_log`. Any staff member may toggle sold-out.
- web `apps/admin/`: Menu (categories, items, option groups, sold-out), Business (name, CRIB, address, footer, receipt language, timezone), Staff (add, rename, role, PIN, deactivate), Tax (view rates, add a dated rate, verified flag).
- POS refetches the menu on `menu.changed` and drops cart lines for removed/sold-out items.
- `start.bat` now always rebuilds the web app (2 s) so it never serves a stale UI.

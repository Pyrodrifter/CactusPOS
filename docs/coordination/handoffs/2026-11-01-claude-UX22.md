## What changed
- **ABB:** Admin > Today shows "No ABB to pay" with the reason, and `exempt` / `no ABB` on the tiles, while Charge ABB is off. The reason is pre-filled in the Tax dialog. The cart and tab sheet drop the "incl. ABB $0.00" line.
- **Ready orders on Order:** `pos/ReadyStrip.tsx`, a panel above the cart (first thing on one-column screens): name or number, items, Not paid + Pay, Picked up, Undo for 8 s. Takes no room when nothing is ready.
- **Names:** `Name for pickup` in the cart (kept in the draft, pre-fills Pay later) is stored as `tabName`. The pickup board shows it instead of the number.
- **Stock:** `Stock` button on the Order toolbar (`pos/Stock.tsx`), any signed-in staff: prepared for today, processed, whole ingredients. +/- per row, tap the row to edit. Prepared items can link menu items and then show prepared, sold and left.
- **UI pass on Order (owner request):** the service switch sits beside search, cart lines are one compact row, menu tiles are lower, the item count shows only while searching, and the green banner that repeated the toast is gone.
- `e2e/tryout-wishes.mjs`, `server/stock.test.ts`; manual text in both languages.

## Contracts touched

## How to verify
`npm run typecheck && npm run lint && npm test`, then `npm run e2e` (11 scenarios). `node e2e/run.mjs tryout-wishes` alone on a fresh till shows Today at $0.00 (`.local/e2e-shots/tryout-today-exempt.png`).

## Gotchas / decisions
- Auto-collect had to go off by default, or a ready order would vanish from the Order row after a minute, before anyone could confirm it. This changes KIT01's default.
- Charge ABB is **not** switched off by code or seed: the product stays general for Bonaire. Each till switches it off once. Sales from before the switch keep their ABB, so that day's Today can show more than $0.00.
- Stock sold-counts are read from orders, never written by the order path, so offline sales and voids stay safe. One sold = one counted; a Cactus Double counts as one (Q36). General stock is by hand.
- Whole numbers only. Practice mode's stock starts empty.
- Schema 8: an older program refuses this database, so going back to rc.5 needs a backup from before the update.
